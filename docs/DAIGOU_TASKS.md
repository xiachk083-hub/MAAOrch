### 玩法速记

- 代币「闲言碎语」：不夜街区 AT-* 作战固定掉落；**100 份 = 开一个营业日**
- 每营业日接见 **3 名客人** + 当日「世路快讯」（小报修正，可影响回合/初始信任/兴味）
- 收益公式：**定金 × 信任倍率（×1 或 ×2，检定过=一本万利）× 兴味倍率（×1.0 ~ ×5.0）**
- 情绪：平和 → 走神 → 焦躁；**到焦躁回合必须立刻结束，否则结算后清信任 + 固定小赚一笔**
- 信任：68 点「望气」达标点亮、100 点 MAX 点亮；检定概率 = 信任值 %
- 兴味：50 达标、114 MAX、196 = 5.0 倍
- 「望气」每营业日 **3 次**，用来照阈值决定收手还是继续
- 客人：5 身份 × 8 性格（飙车党 450/8回合、体面人 1200/9 最值钱、危险分子 900/10、追星族 450/10、一般路人 300/11）；特殊客人：澪、惟任警官、萌萌香、星熊
- 目标：相谈室累计入账 **200000**（奖励线 4000 ~ 200000 全拿满）
