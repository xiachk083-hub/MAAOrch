# 打关动作地图：原子动作 → 语义动作 → 流程

> 2026-09-15 立项。用户："我们需要想一下，需要一些流程、哪一些动作。"
> 目的：把"打关"拆到可实现的粒度，并明确每个动作的**前提状态 / 后置验证 / 失败处理**，
> 避免今晚那种"点坐标硬试 → 反复选人 → 卡死"的混乱。
> 配套：`docs/SKILL_EMULATOR_OPS.md`（操作技能）、`docs/CLEARING_AGENT.md`（Agent 架构）。

## 0. 设计原则（每条都对应今晚的一个坑）

1. **一切动作都有前置状态**：不在正确界面上就不许执行（今晚把节点坐标点在编队页上 = 反复选人）。
2. **一切动作都有后置验证**：点完必须确认界面变了（≤1s），没变则按"重试一次 → 换策略"处理。
3. **一切等待都是状态等待**（`wait_until(state, timeout)`），不许 sleep（今晚盲等 150s）。
4. **同一动作不许循环重复**（点节点只在"地图→关卡页"跳变时做一次）。
5. **谁控制谁负责**：执行动作的同一时刻只允许一个控制者（MAA 或 agent）。

## 3. 流程（场景级编排）

### 流程 1：**打通一关**（核心流程）
```
goto_stage → open_battle → form_squad(plan) → start_battle
   ↓
 battle_loop: 每 ~1s 读状态+战场
     ├ 规则决策（费用/技能/波次表）→ deploy/use_skill/retreat
     └ 异常 → LLM 兜底（可选）
   ↓
 判定: win → verify_stars → dismiss_result → next_stage（有下一关就继续）
       fail → dismiss_result → 归因（用时/最后一步/部署失败）→ 改招 → 重试（换 plan 或调站位）
```
产物：`data/plan_loop/<stage>/ledger.json`（每轮 plan + 结果 + 归因 + 三星）

### 流程 2：**日常挂机**（MAA 路线，今晚已验证可用）
`MAA 跑作业 json → 状态机只监控（不干预）→ 台账记录练度证据`

### 流程 3：**练度核对**（打关前必做）
`读干员盒 → 核作业要求（等级/精英/专精/模组）→ 台账/图像识别补缺 → 输出"能跑的作业清单"`

### 流程 4：**异常兜底**（每类一个策略，绝不通吃）
剧情 / 通用弹窗 / 理智不足 / 掉线重连 / 编队失败 / 干员缺失 —— 各自一个 handler

### 流程 5：**失败归因 → 改招**（这就是"重新编排"）
| 证据 | 归因 | 改招 |
|---|---|---|
| 用时 < 90s 就崩 | 漏怪 / 挡位被秒 | 按路线数补挡位、换更硬的挡、加奶 |
| 打到后期没收掉 | 输出不够 | 换高 DPS（法抗高→物理，防高→法术）、加输出位、开技能策略 |
| 日志「干员不可用/编队失败」 | 练度不够 | 换作业/借满配/先练关键干员 |
| 动作没生效（如部署没落地） | 格子冲突/费用不足 | 调部署顺序、换格 |

## 6. 战斗内循环：**暂停中思考**（2026-09-15 用户点出）

参考实现（B 站 GPT-6 那套）在思考时**直接把游戏暂停**，我们原来是"边跑边想"——局面会在思考期间漂移，
这也是时序类动作失败的来源。规则改为：

```
暂停 → 取图 → 判状态 + 读战场数字(费用/敌人余量/可部署位/技能就绪) → 决策
     → 恢复 → 立刻执行动作(部署/技能，坐标与时序预先算好) → 等状态变化 → 下一个决策点
```

- **游戏暂停时不能部署**，所以"观察/决策"在暂停里做，"动作"在恢复后瞬间做（MAA 抄作业同原理：
  每步前 `BattlePause`，所以它时序准）。
- 现成坐标（从 MAA 任务取得，1280×720）：
  - 暂停/继续：**(1200, 50)** ← `BattlePause` specificRect [1170, 20, 60, 60]
  - 倍速：**(1100, 50)** ← `BattleSpeedUp` specificRect [1070, 20, 60, 60]
- **暂停时机由波次表驱动**（`data/_level_*.json` 的 spawn 时间）：关键波前 ~1s 暂停从容决策；
  其余时间 2 倍速跑。
- 站位/朝向/技能次序仍**离线算好**（`derive_plan.py`）；暂停只用来"看偏差、改偏差"，不重新发明打法。
