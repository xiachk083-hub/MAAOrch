## 4. 换关通用流程（本次沉淀）

1. `tools/stage_cut.py --stage <id>`：地形/路线/最小割；`--block "x,y ..."` 验证堵口覆盖（自动识别行号上下翻转）。
2. `tools/stage_arrivals.py`：每路出兵/到达时刻表 ⇒ 判断哪几波同时到达、需要几个阻挡位。
3. `tools/roster_scan.py --keys 抵抗 冻结 免疫`：从自己账号里按**技能/天赋描述关键词**找对症干员（不是无脑三技能）。
4. 设计轴：先定「杀伤区」，再把阻挡位放进杀伤区；冰面图优先谢拉格 + 能解异常的奶。
5. `tools/stage_attempt.py --job <job> --tag <tag>`：跑局 + 录像 + OCR 结算页判定（不做导航）。
6. 复盘：`tools/stage_cut.py --block`／`tools/ce6_battle_audit.py` 看漏怪时刻（注意 `screenrecord` 上限 180 s，长局要分段录）。
