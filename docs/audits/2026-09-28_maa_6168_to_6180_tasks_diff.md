判定口径（与 `guard` 的 verdict 对齐）：

- **关注节点全部在位、且我们依赖字段无 schema 漂移** ⇒ 本次跨版本差异属「新增能力/新关卡」型，**升级本身不改变我们链的走法**；
- 若 `SwitchAccount@StartUpBegin`/`StartUpBegin` 等**消失或改名** ⇒ 切号注入可能被 MAA 改名打穿，按 `docs/MAA_UPGRADE_GUARD.md` §3 走 D3（升级打穿注入层）处置；
- 若 `Fight@StartButton`/`Recruit`/`Mall`/`Award` 消失 ⇒ 对应 AutoProxy 子任务链可能失效，先停当晚发车再排查。

> 注：本样例以**资料性**为准——6.16.8/6.17.5/6.18.0 三份原件在 `fixtures/`，可随时用
