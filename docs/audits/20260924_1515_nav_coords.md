## 5. `tools/nav_map.py` 改了什么

1. **删两张死表**（`NODES` / `ZONE_CARDS`）→ 换成指回真源的注释 + `DATA = ROOT/"data"/"nav_nodes.json"` + `load_cfg()` / `_is_xy()`。注释里写明“**改坐标只改 json**，别在本文件里再建第二份表（两份必然漂移）”。

3. **`coord_src` 透传/补充**：转发 `/nav` 之后 `r.setdefault("coord_src", ...)`、`r.setdefault("coord_src_from", "cli"/"server")`；判定顺序 = 服务端给了就用服务端的 → `from_learned_nodes` ⇒ `learned`（模型坐标库）→ `learned_node` ⇒ `auto_scan`（自动试点命中并已学习）→ 有 `point` 且命中坐标表 ⇒ `table`（坐标表命中）→ 否则 `auto_scan` / `none`。人类可读行也显示“｜来源 坐标表命中（CLI 推断）”。
4. **没动**：`svc()` / `shot()` / `what()` / `page()` / `--stage` 的转发逻辑与 8765 的启动方式。
