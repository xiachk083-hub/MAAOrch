usage: stage_capability.py [-h] [--build] [--update] [--rebuild-local]
                           [--replay RAWJSON] [--days DAYS]
                           [--update-days UPDATE_DAYS] [--account ACCOUNT]
                           [--json] [--no-write] [--timeout TIMEOUT]
                           [--selftest] [--check]

账号×关卡 可刷能力台账（数据源只读；**默认写盘**，干跑加 --no-write）

options:
  -h, --help            show this help message and exit
  --build               全量重建（扫主机最近 N 天；默认写盘，干跑加 --no-write）
  --update              增量（只扫最近 N 天并入 state；默认写盘，干跑加 --no-write）
  --rebuild-local       从 state 重算报告（不联网；默认写盘，干跑加 --no-write）
  --replay RAWJSON      用已抓取的原始扫描 JSON 重建（离线；默认写盘）
  --days DAYS           窗口天数（默认 30）
  --update-days UPDATE_DAYS
                        增量扫描天数（默认 3）
  --account ACCOUNT     只看某个账号（读台账，不联网）
  --json                打印机读 JSON
  --no-write            不写盘（干跑；本工具默认真写盘，与其余工具默认 dry-run 相反）
  --timeout TIMEOUT     SSH 超时秒（默认 1500）
  --selftest            离线分类器自检
  --check               连通性自检
