# 核实：账号切换开关是否"切一次后自动取消"（含重置层定位）

- 任务：t_e43fecf4（mas）· 2026-09-27 晚 · 只读观测 + 源码核实

## 结论（先说）

**不会。** 不存在"账号切换开关在切换一次之后自动取消勾选"的行为：

1. **MAA 自身无此行为**（v6.18.0 源码穷举写入点，仅 UI 勾选 + 一次性的旧配置迁移；运行期没有任何路径把
   `AccountSwitchEnabled` 置 false）。实测：单号整个周期（注入→切换→跑完→退出写回）值始终 true。
2. "勾选消失"的真实来源 = **AUTO-MAS 配置分层**，按可能性排序：
   - **轮末快照还原（已实证）**：`manager.py final_task()` 在轮末用轮起快照（Temp）覆盖回 MAA 配置目录。
     今天上午轮实测：还原把运行终态 true 覆盖回快照 false → 事后查配置文件就是"未勾选"的样子。
     **写回者是 AUTO-MAS 的还原动作，不是 MAA。**
   - **每用户注入重写**：`AutoProxy.set_maa()` 每号 spawn 前整份重写配置；v2 策略：Official=true+掩码，其他=空+false
     （非官服脚本看到的永远是 false）。
3. 以上文件层的 false **不影响切号**：每号 spawn 前重新注入 true。今天上午一轮 4 个号全部切换成功
   （134****5276 → 139****8825 → 130****9165 → 187****8608）为直接实证；"第 2 个号起失效"不成立。
