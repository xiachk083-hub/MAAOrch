- 「刷够 N 次」**不是**可用字段（AUTO-MAS 两层无总次数字段，简洁模式 EnableTimesLimit 硬关）：§4 的「≈N 次」只是缺口估算，别当上限。
- 跨 04:00 / 19:00 宿主计划重启窗口会中断任务（事件 id=1074）——长跑请错峰。
