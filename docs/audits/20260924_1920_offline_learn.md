# 离线补 learned 关卡清单（不占模拟器）+ `--shot` 本地 OCR 化

日期：2026-09-24 19:20 ｜ 执行：mas ｜ 相关：`tools/discover_stages.py`、`runtime/learned/stages_*.json`

## 0. 一句话

`--shot` 离线重放原来**只走 modlens 视觉模型**（那条链现在挂着：openai schema 不匹配 / anthropic 400
MissingSessionID）⇒ 看起来"离线学不动"。其实**关卡代号是白框里的 ASCII**，队列自己那套本地 OCR
（`infrastructure/ocr.py` → rapidocr_onnxruntime，`ocr_tool.py` 是同一批 PaddleOCR ONNX）读它
**置信度 0.99+**。给工具加了一条本地 OCR 路 + 多帧并集，于是 PV/MT/LE/AD 的清单**今天就能离线补齐**，
不必等 modlens，也不必占模拟器（队列那一刻正在跑 CV-EX-8）。

## 1. `tools/discover_stages.py` 改了什么

| 改动 | 为什么 |
|---|---|
| 新增 `codes_from_local_ocr()`：`--shot(s)` 先走本地 OCR，认不出才回落到 modlens | 离线学习不再单点依赖外部视觉后端；零网络、可复现、快 |
| 新增 `--shots a.png,b.png`：**同一区**多帧**取并集** | 地图要平移才看得全：`_map_LEEX_left` 只有 LE-EX-1/2/3，`_map_LEEX_mid` 只有 4~7，单帧永远 7/8 而且**看起来像图上就这么多** |
| `CODE_RE` 补 `TR-` | `stages_EA.json` 的 diag 里 OCR 明明读到 `EA-TR-1`，落库时被丢掉；本地 OCR 也读到 `AD-TR-1`/`PV-TR-1`（0.99） |
| `keep()` 取代 `startswith(prefix+"-")` | OCR 会把白框左边的图标粘进同一个 token：实测 `ILE-EX-6` ⇒ 用 startswith 时 **LE-EX-6 被静默丢掉** |
| `--partial "<原因>"`（按区记进 `areas[key].partial` ⇒ `warnings`） | **局部帧必须自报残缺**：`maybe_learn_stages` 的重学条件是 `age>12h 或 warnings非空且age>2h`（`_prime_queue3.py:1297`）⇒ 无告警的残清单会**静默锁死 live 重学 12 小时** |
| `--prefix AD,EA` ⇒ 直接 exit 2 + 说明 | argparse 单值 + `f"stages_{prefix}.json"`：逗号列表必然 0 codes，原来只是"神秘地什么都没学到" |

## 4. AD 的**顺序**（关键，容易误操作）

`stages_AD.json` 的 `areas.main.codes` 里存的是 **AD-EX-1/2/3**（18:25:07 那次屏在 EX 区、落库键却
是 `main`）。**直接** `--shot runtime/_ad_map.png --prefix AD --area main --save` 会**覆盖 main** ⇒
那 3 个代号从顶层 `codes` 并集消失 ⇒ AD-EX-1..3 失去**唯一**的"图上存在"证据 ⇒ 沉 tier 2。

所以顺序是：**① 先把 3 个 EX 代号搬回 `areas.ex` ② 再重学 main**。
已按此执行（脚本：`ad_rekey.py`，可复跑为 dry-run）。修复后顶层 = 9，`_recovered` 字段记了来龙去脉。

## 5. 顺带查清的两件事

* **面板预扫缓存是干净的**：`learned/panels_AD_main.json`（18:26:10，`live-scan`）里记的是
  AD-1..8 + AD-ST-1/2（10 个主区节点，全 `unknown`），不是 EX 代号 ⇒ 没被那次错键污染。
* **CV 主区死锁确认存在**：runtime 里唯一的 CV 地图帧是 `_cv1.png`（EX 图）。learned 只有 ex 区 ⇒
  CV-1..7 图上无证据 ⇒ tier 2 ⇒ 永不排产 ⇒ `maybe_learn_stages` 等不到 CV 非 EX 单位去触发 main 学习。
  **只能外部打破**（进图后 live 学一次 CV 主区，或手工补 `areas.main`）。

## 6. 还剩什么必须占机（live）

CV 主区｜EA 地图（runtime 无任何 EA 活动地图帧）｜MT 主区左半（MT-1..5 / MT-ST-1/2）｜
LE 主区右半 + LE-EX-8｜AD 主区右半（AD-5..8 / AD-ST-2）与 AD EX 图｜PV 的边角节点。

**好消息**：这几项**都不需要中断队列**——它们全是 `--partial` 告警覆盖到的区，进图后 2h 就会自动重学。
