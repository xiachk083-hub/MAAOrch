# 快速上手

## 环境要求

- Windows 10/11
- Python 3.12+
- MuMu 模拟器 12（可选，也支持其他模拟器）

## 安装与启动

```bash
# 1. 下载项目
git clone https://github.com/xiachk083-hub/MAAOrch.git
cd MAAOrch

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动（推荐）
python main_web.pyw --no-elevate
```

启动后自动完成：
- 检测 `services/maa/source/` 是否有 MAA → 没有则自动从 GitHub 下载
- 运行一次 MAA.exe 生成初始配置（`$type` 等必要字段）
- 创建实例池 → 启动 Web 服务器 → 打开浏览器

**也可以双击 `main_web.bat` 启动**（自动装依赖、启动服务器、打开浏览器）。

## 访问

| 方式 | 地址 |
|------|------|
| 本机 | http://127.0.0.1:19999 |
| 局域网 | `http://{你的IP}:19999`（默认绑定 `0.0.0.0`） |

## 使用流程

### 1. 配置关卡（可选）

设置页 → 关卡管理 → 添加常用关卡（如 `1-7`、`CE-6`、`AP-5`）。
也可以在账号页的**表格模式**中直接新建关卡列。

### 2. 创建账号

账号页 → 创建 → 填写名称和游戏客户端（官服/B服/外服）。
**批量创建可用 CSV 导入**：账号页 → 📋 CSV 编辑 → Excel 拉表 → 保存。

### 3. 关联模拟器

每个账号需要指定模拟器实例索引（0、1、2...），对应 MuMu 多开管理器的 VM 编号。
在账号编辑中设置 `emu_instance_index`，或通过表格批量填写。

### 4. 一键调度

仪表盘 → 选择调度模式（日常/含剿灭/仅剿灭）→ 一键调度。
系统会自动按账号配置分配任务并入队列。

### 5. 查看运行状态

仪表盘实时显示各账号运行状态、系统资源、MAA 进程。
日志页面可查看 MAAOrch 和 MAA 的详细运行日志。

## 账号批量管理

### CSV 编辑

账号页 → 📋 CSV 编辑 → 弹窗显示 CSV 文本：
```
id,名称,游戏客户端,模拟器索引,切换标识,UID,备注,过期日,已暂停,剿灭
V000001,V,Official,1,9036,,,,,Annihilation
```

- 复制到 Excel 修改后粘贴回来 → 保存
- 或者下载 `.csv` 文件 → Excel 打开 → 保存 → 从文件导入
- 新建账号时 `id` 留空，自动生成

### 表格编辑

账号页 → 📊 表格 → 进入可编辑表格视图：

- 每行一个账号，每列一个字段
- 关卡列为勾选框（来自关卡库）
- 剿灭列为下拉框（`Annihilation` / 龙门外环 / 龙门市区 / 切尔诺伯格）
- 游戏客户端为下拉框（官服/B服/外服）
- 点「保存表格」一次性提交所有更改
- 支持新增行、删除选中、新增关卡列

## 常见问题

| 问题 | 解决 |
|------|------|
| 双击没反应 | 用 `main_web.bat` 启动，或 `python main_web.pyw --no-elevate` |
| MAA 不启动 | 检查 `services/maa/source/MAA.exe` 是否存在 |
| 远程打不开 | 默认绑定 `0.0.0.0`，检查防火墙和网络 |
| 模拟器连不上 | MuMu 多开管理器重启模拟器 |
| 下载 MAA 失败 | 手动下载解压到 `services/maa/source/` |
